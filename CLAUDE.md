# Piepie Challenge Tracking App

## Tech Stack
- Frontend: [e.g., React, Next.js, Vue, or React Native]
- Styling: Tailwind CSS (Sleek dark mode, magenta `#E91E63` accents, rounded cards)

## Application Structure & Navigation
1. **Home / Landing**: Action button for "Add activities", Classic Challenge targets summary card, Ultra Challenge targets summary card, rounded bottom buttons for "Activities" and "Profile".
2. **Activities**: User profile metrics header, Classic & Ultra progress tiles, daily activity log table (with Edit/Delete controls), interactive monthly training calendar, and floating "+" button.
3. **Profile**: User info inputs (Name, Email, Cell), Race Number display, Challenge toggle (Classic vs. Ultra), sport category checkboxes, "Save updates" button, and "View progress" button (redirects to progress section on Activities page).
